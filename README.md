# plx-caregiver

The iPhone app is native SwiftUI. Open [PrimaLuxCare.xcodeproj](./PrimaLuxCare.xcodeproj) and press Run. Steps are in [OPEN-IN-XCODE.md](./OPEN-IN-XCODE.md). Do not use the Expo project to install on a Mac.

PrimaLux Care is a private family hub for coordinating care: calendar, tasks, medications, and updates. This native build keeps that care on the iPhone. The older Expo tree is still in the repository and is not the install path.
